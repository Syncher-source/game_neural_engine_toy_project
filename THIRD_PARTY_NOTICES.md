# Third-party components

Nothing third-party is vendored in this repository. The build and the Python environment
download the following at configure / install time; each keeps its own licence.

| component | used by | licence | how it gets here |
|---|---|---|---|
| ONNX Runtime | C++ renderer and optional world model | MIT | CMake downloads the release package into `cpp/third_party/` |
| NVIDIA CUDA runtime, cuBLAS, cuFFT, cuRAND, NVRTC, nvJitLink | ONNX Runtime CUDA provider, deterministic kernel (NVRTC) | NVIDIA CUDA Toolkit EULA (redistributable components) | CMake downloads NVIDIA's redistributable archives into `cpp/third_party/cuda/` |
| NVIDIA cuDNN | ONNX Runtime CUDA provider (Windows) | NVIDIA cuDNN licence | same |
| SDL3 | C++ client window, input, gamepad | zlib | vcpkg (`cpp/vcpkg.json`) |
| PyTorch, NumPy, Pillow, pygame, onnx | Python training / export pipeline | BSD-3 / BSD-3 / MIT-CMU / LGPL (dynamic) / Apache-2.0 | `uv sync` |

The CUDA and cuDNN redistributables are downloaded by the person building the project and
are not part of this repository or of its licence. Check NVIDIA's terms before redistributing
a built `bin/` directory that contains them.

The sprite art in `assets/sprites/` is generated by `nge/sprites.py` and is covered by the
repository's MIT licence.
